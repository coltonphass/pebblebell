# Pebblebell website

The public pages for [Pebblebell](https://coltonphass.github.io/pebblebell/), a meditation app for
Android, served by GitHub Pages from this repository's main branch:

- `index.html`: the home page
- `test/`: how to join the test on Google Play
- `privacy/`: the privacy policy, linked from the Play Store listing

Plain HTML and one stylesheet; no build step. The app itself lives in a separate repository.
